Project Title: Rankly.ai – AI-Powered Automated Recruitment Intelligence & ATS Platform
Module Focus: Week 2: Database Modeling, Schema Architecture & Backend Foundation
Detailed Work Completed / Technical Implementation:
  • Relational Database Architecture: Engineered a scalable relational data model using Prisma ORM with PostgreSQL (and SQLite development fallback). Defined comprehensive entities: User (with Role enums: CANDIDATE, RECRUITER, ADMIN), Organization, JobRequisition, CandidateProfile, ResumeDocument, SkillAssessment, OtpVerificationToken, and AuditLog.
  • Relational Integrity & Indexing: Established Foreign Key cascades, unique compound indexes on (orgId, jobCode) and (userId, email), and B-Tree indexes on search query attributes (skills, location, status) to ensure sub-10ms query execution times.
  • Express REST API Gateway: Built a modular Node.js/Express server architecture featuring structured routing (/api/auth, /api/candidates, /api/jobs, /api/analytics, /api/health) with request validation pipelines.
  • Authentication & Cryptographic Security: Configured JSON Web Token (JWT) asymmetric signing with configurable TTL, bcrypt salt-round 10 password hashing, Helmet security headers, CORS origin whitelisting, and centralized error handling middleware.
  • Database Migration Pipeline: Created automated Prisma migration scripts (prisma migrate dev), database seed scripts with mock enterprise data, and connection pooling configurations for Railway deployment.
Key Deliverables & Verified Output: Prisma schema with 8 relational models, 14 foreign keys, complete REST API gateway with 16 core endpoints, and verified database seed scripts.
Guide's Remark: Excellent technical depth. The architecture diagrams, code implementations, and security standards demonstrate thorough milestone completion.

Module Focus: Week 3: Dual-Persona Authentication, Onboarding & Multi-Tenant Security
Detailed Work Completed / Technical Implementation:
  • Dual-Persona Sliding Auth Architecture: Designed and built an interactive sliding authentication UI featuring two distinct user workflows (Candidate Registration vs Enterprise Recruiter Workspace Sign-In) inside a single fluid container.
  • 3D Card Flip & Magic UI Integration: Integrated full 3D card flipping CSS transforms (perspective: 1000px, transform-style: preserve-3d) alongside Magic UI animated luminous border beams (--border-beam-from: #D95D39, --border-beam-to: #5B998C) with zero UI layout shift.
  • Email OTP Verification Engine: Implemented a secure OTP generation service generating cryptographically random 6-digit verification codes, stored with SHA-256 hashes and 10-minute expiry timestamps in PostgreSQL.
  • Anti-Abuse & Rate-Limiting Controls: Engineered sliding-window rate limiters restricting OTP requests to maximum 3 attempts per 15 minutes per IP/email, complete with real-time UI countdown timers and resend throttling.
  • Role-Based Access Control (RBAC): Developed Express authorization middleware (verifyRole(['RECRUITER']), verifyRole(['CANDIDATE'])) strictly preventing unauthorized privilege escalation across tenant boundaries.
Key Deliverables & Verified Output: Production-ready sliding auth card with 3D flip physics, end-to-end Email OTP verification pipeline with rate-limiting, and strict RBAC authorization middleware.
