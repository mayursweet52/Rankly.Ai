# 🗺️ Implementation Phases & Roadmap – Rankly.ai

---

## ✅ Phase 1: Authentication, Access Control & Dual-Track Roles
* [x] Dual-track Login & Signup (Normal Candidate vs Company / Employee).
* [x] Google OAuth & GitHub OAuth integration with automated profile sync.
* [x] Email OTP verification for secure password reset (Nodemailer Gmail SMTP).
* [x] Admin referral code generator for provisioning HR and Hiring Manager teammates.
* [x] Account profile customization and permanent account deletion.

---

## ✅ Phase 2: Multi-Metric ATS Resume Screening Engine
* [x] Drag-and-drop resume ingestion (`.pdf`, `.docx`, `.txt`).
* [x] Multi-metric weighted ATS scoring formulation (40% skills, 25% experience, 20% tools, 15% education).
* [x] Candidate name extractor with header-filtering heuristics.
* [x] Expandable evaluation cards with matched competencies, skill gaps, and recommendations.
* [x] Candidate avatar and passport photo upload support.
* [x] 1-Click "Send to HR" forwarding action for hiring managers.

---

## ✅ Phase 3: Talent Pipeline (Kanban) & Candidate Tracking
* [x] 4-stage interactive Kanban board (`Screening`, `Interview`, `Offer`, `Hired`).
* [x] 1-Click stage transitions and dynamic candidate counter badges.
* [x] Quick candidate removal and stage reallocation.

---

## ✅ Phase 4: AI Career Advisory & Resume Blueprint Studio
* [x] Conversational AI Chatbot with 10-provider fallback cascade.
* [x] Quick suggestion chips for rapid career queries.
* [x] STAR-method AI Resume Builder generating tailored bullet points and keyword clusters.
* [x] 1-Click copy Blueprint to clipboard.
