Deep Component Analysis

Based on a direct read of server.js, prisma/schema.prisma, and src/services/, this is the exact mechanical behavior of Rankly.ai:

1. Ingress & Security Stack (server.js)

  • Reverse Proxy: Configured to trust load balancers (Render/Heroku).
  • Helmet.js: Disables fingerprinting (x-powered-by) and locks down CSP headers.
  • Compression: Uses Gzip/Brotli for payloads over 256 bytes for instant UI rendering.
  • Triple Rate-Limiting: apiLimiter, publicLimiter, and authenticatedLimiter secure the API from DDoS.

2. The 29-Route Matrix

  • The system is split into massive modular routers: pipelineRoutes.js for ATS logic, grievanceRoutes.js and attendanceRoutes.js for HR operations, backupRoutes.js for DB snapshots.
  • Export Engine: exportRoutes.js triggers exportService.js, serializing complex DB queries into downloadable Excel/CSV files.

3. AI & Vector Processing Pipeline

  • documentParserService.js: Mechanically extracts pure semantic text from uploaded PDFs/Word docs.
  • vectorSearchService.js: Implements advanced RAG (Retrieval-Augmented Generation) embeddings.
  • aiMatcher.js: Streams data directly to NVIDIA Nemotron AI to calculate fit scores and extract structured JSON skills.

4. Relational DB Mechanics (Prisma Schema)

  • ATS Pipeline: CandidateApplication tracks users through strict stages (pending → ai_shortlisted → hr_review).
  • HRMS & Compliance: Grievance handles confidential reports; Attendance tracks exact shift hours; LeaveRequest manages approval flows.
  • Immutable Audit Trails: The AuditLog table permanently records every state change, IP address, and actor ID for compliance.

5. Socket.IO Realtime Engine

  • Unlike typical REST apps, Rankly boots a native Socket.IO server linked to realtimeNotificationService.js.
  • When AI finishes evaluation, it emits WebSocket payloads directly to the recruiter's browser, updating the queue instantly without a refresh.

6. Hybrid Email Workers

  • Standard emails use Nodemailer (emailService.js).
  • A dedicated Python subprocess (pythonEmailSender.py) handles legacy SMTP or bulk-queued email processing.
