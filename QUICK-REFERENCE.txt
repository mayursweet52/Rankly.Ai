# Rankly.ai - Quick Reference Card

## 🚀 LAUNCH APP
```
1. Double-click: Rankly.ai (Desktop Shortcut)
   OR
2. Run: start.bat in app folder
   OR
3. Run: setup.bat (first time only)
```

## 🌐 OPEN IN BROWSER
```
http://localhost:3000
```

## 🔑 API KEY
```
Default: rankly-secret-key
(Change in .env for production)
```

## ⚙️ CONFIGURATION (.env)
```
PORT=3000                           (Server port)
OLLAMA_URL=http://localhost:11434  (AI engine URL)
OLLAMA_MODEL=llama3.2:3b           (AI model)
API_KEY=rankly-secret-key          (Authentication)
```

## 📁 KEY FILES
```
start.bat              → Launch server
setup.bat              → Initial setup
server.js              → Main application
package.json           → Dependencies
.env                   → Configuration
rankly-icon.ico        → Custom icon
rankly_candidates.db   → Database
```

## ⚡ COMMANDS
```
npm install            Install dependencies
node server.js         Start server manually
npm run dev           Run with auto-reload
Ctrl + C              Stop server
```

## 🔧 TROUBLESHOOTING
```
Issue: Port in use
→ Change PORT in .env

Issue: Node not found
→ Install from nodejs.org

Issue: Dependencies error
→ npm cache clean --force
→ npm install

Issue: Icon missing
→ python create_icon.py
→ Run Create-Shortcut.ps1
```
